EmilyDesk Wallpaper Collection

This folder contains two approved wallpapers for each EmilyDesk theme.
Every design is supplied in both supported 4K formats:

3840 x 2160 (16:9)
3840 x 2400 (16:10)

The Dashboard Wallpaper section selects the best format automatically for the
primary display. Users may also choose either resolution manually, select a
personal image, change the Windows wallpaper layout, or restore the wallpaper
that was active before EmilyDesk applied one.
