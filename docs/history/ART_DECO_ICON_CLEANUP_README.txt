Art Deco weather icon cleanup
==============================

This package corrects five Art Deco weather icon PNG files only.  No Designer,
widget, layout, weather-provider, or installer code has been changed.

To apply this correction to an existing EmilyDesk installation:

1. Exit the Art Deco Weather widget from its right-click menu.
2. Double-click Apply-Art-Deco-Icon-Cleanup.cmd in this folder.
3. Re-launch the Art Deco Weather widget.

Do not run Build.cmd and do not run the installer for this correction.

The repair updates only these installed image files:
  3.png, 4.png, 6.png, 11.png, and 32.png
