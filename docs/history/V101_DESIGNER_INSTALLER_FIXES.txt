DESIGNER AND WIDGET FIXES
1. Font names now have an installed-font drop-down. The Fonts menu can also
   import a TTF/OTF into the current widget's persistent DesignerAssets folder.
2. Divider layers can be added from the Layers menu or canvas context menu.
3. Main and weather-details backgrounds are real selectable/resizable layers.
   Bitmap themes use their PNG; Modern and Vintage render their native frame.
4. Closing, opening, or replacing a changed live layout asks Save/No/Cancel.
5. Each widget Opacity menu has a persistent "100% while mouse is over widget"
   option, including per-pixel-alpha widgets.
6. WeatherAPI requests four days. A provider response with fewer than four
   automatically falls through to the next configured provider, avoiding blank
   forecast slots. Steampunk's intentional three-day presentation is unchanged.
7. Replacing a selected clock hand opens that theme's actual Assets\Themes
   folder instead of an empty DesignerAssets clock folder.
8. Botanical weather-detail glyphs use a high-contrast dark green palette.
9. The 64 MB and pixel-dimension PNG rejection was removed. Imported clock
   hands remain resizable in Designer.

INSTALLER AND WEATHER SERVICE
- The maintained installer is Installer-UserMode.iss (the old filename is kept
  for build compatibility, but the setup now requires administrator rights).
- Application binaries install under Program Files. The LocalSystem service,
  WeatherCore, Shared DLL, and provider profiles use a private protected
  Program Files\EmilyDesk\WeatherService directory.
- SetupHelper refuses to deploy a service payload from any other directory.
- The service listens only on http://127.0.0.1:45873/. No hosts-file bootstrap
  or manual PowerShell step is installed.
- Upgrade removes the obsolete api.accuweather.com URL reservation and hosts
  entry, then replaces and health-checks the service. A failed health check
  aborts setup and removes the partial service deployment.
- Service data moves to ProgramData\EmilyDesk\WeatherService. Existing
  locations, provider settings, API keys, and caches are copied forward when
  the new destination does not already contain them; legacy data is not erased.
- Uninstall removes the service, URL reservation, and protected service files.
  It intentionally retains LocalAppData layouts/settings and ProgramData
  weather data.
- Installer file/product version metadata now matches 2.10.27.
- Build.ps1 can Authenticode-sign all application binaries and the installer
  when EMILYDESK_SIGN_CERT_SHA1 names a trusted code-signing certificate.
  Set EMILYDESK_REQUIRE_SIGNATURE=1 for a release build that must fail rather
  than emit an unsigned installer.

LARGE PNG RESIZE PERFORMANCE - 2026-09-07

  is displayed. It no longer reopens and recreates a large clock-hand bitmap

DESIGNER EDITING REFINEMENT - 2026-09-07
- Replaced the always-open raw property grid with a plain-language selected-

  fonts, alignment, clock-hand role, and panel behavior use drop-downs.
- The installed-font list is available directly beside the selected text

- Layer rows now have clickable visibility and lock icons. The bottom layer

- Clock-hand preview rotation has a 0-359 degree slider linked to an exact

  options; the ordinary editor no longer exposes True/False text values.
- Installed Designer saves package artwork under the writable shared layout
  data folder and writes PNGs atomically. This avoids the GDI+ warning caused
  by overwriting protected or in-use package images under Program Files.
- The gallery checks for each theme's user-generated Designer preview before
  falling back to the bundled preview.
- The Windows Designer verification now checks independent clock-hand mouse
  dragging, corner rotation, slider/numeric synchronization, persisted runtime
  alignment, large-image caching, and repeated atomic PNG updates.

CLOCK-HAND FLEXIBILITY AND DRAG REGRESSION CORRECTION - 2026-09-07
- Replaced the fixed thin-pointer/tail model for imported clock-hand PNGs with
  an image-local pivot. New and replaced hand PNGs default to 50% across and
  50% down, matching XWidget artwork with balanced transparent canvas.
- Pivot-across and pivot-down controls allow the rotation point to be placed
  anywhere inside unusual, curved, or asymmetrical PNG artwork. Center
  (XWidget), End of canvas, and Legacy tail presets are included so the
  original hand behavior remains available alongside centered PNG rotation.
- Each hand now has independent X, Y, width, height, pivot, and alignment.
  Selecting a hand in the Layers list and dragging its body keeps that exact
  hand selected even where clock layers overlap.
- The square lower-corner handle resizes proportionally around the chosen
  pivot. The round upper-corner handle rotates clockwise or counter-clockwise;
  the linked 0-359 slider and exact numeric value remain available.
- Saved rotation is now part of the runtime layout contract and is added as an
  alignment offset to the live hour/minute/second angle. Older saved preview
  angles remain ignored until Designer performs the one-time hand migration.
- Runtime custom-hand images are decoded once and cached near their rendered
  dimensions (capped at 2048 pixels) instead of retaining and resampling a
  potentially enormous source PNG on every clock repaint. This addresses the
  desktop clock drag delay introduced by very large replacement hands.
- No automatic operation moves the clock hub or other hands. Align this and
  Align all are the only commands that intentionally share a dial position.
