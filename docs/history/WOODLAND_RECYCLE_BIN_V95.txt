CHANGED
Woodland Nature Recycle Bin empty/full images only, plus release versions.
The flat bucket is replaced by a realistic dark wooden barrel with worn iron
hoops and a matching full state containing crumpled paper and a takeaway cup.
Both images are 1024 x 1024 RGBA PNGs. Surrounding pixels have alpha = 0,
not a painted checkerboard or a colour-key background. The silhouette has
anti-aliased edges, checked against light and dark backgrounds.
The front rim and barrel body are pixel-identical in both states, with shared
canvas registration so the bin does not jump or resize when its state changes.

UNCHANGED
All C# source, widget behavior, approved v94 snapping fixes, settings, docks,
Designer, other theme artwork and Windows desktop Recycle Bin icon feature.
The existing caption and item count remain. This is still the actual Recycle
Bin widget: open, empty with Windows confirmation, drop to recycle, and live
empty/full updates. The other six widget themes retain their current artwork.

BUILD AND TEST
Extract the ZIP into a new location, keeping its top-level EmilyDesk folder.
Run EmilyDesk\Build.cmd as usual, then use the newly generated package.
Choose Woodland Nature Recycle Bin in the Gallery (or its Theme setting).
Check the empty and full appearance on your wallpaper and at your usual scale.
Use only a disposable test file if checking drop-to-recycle behavior; do not
empty existing personal files solely to test this artwork.

VALIDATION
Both PNGs decoded and checked for real alpha, clear canvas borders and identical
barrel-body pixels. All pre-existing files are retained. All runtime, Designer,
dock and widget C# files are byte-for-byte identical to v94. Gallery previews
are regenerated by the unchanged Windows build workflow.
The Windows/.NET build and live desktop behavior could not be executed in the
Linux development environment; please run Build.cmd and test on Windows.

Empty prompt specification:
Use the supplied empty-bin screenshot as a style reference for its realistic
dark wooden barrel, not the illustrated bucket or metal bins. Photorealistic
dark oak, deep walnut grain, worn black iron hoops, hollow interior, slightly
elevated front view and soft upper-left lighting. Isolated on transparency,
with room above the rim for the full state; no UI, text, scenery or cartoon
styling. A targeted extraction edit preserved the barrel while requesting a
genuinely transparent background. The generated checkerboard was subsequently
removed locally, preserving opaque material pixels and decontaminating edges.

Full prompt:
Use case: precise-object-edit. Asset type: photorealistic desktop Recycle Bin
widget FULL-state sprite. Image 1 is the exact EMPTY-state edit target.
Preserve the barrel body, wood grain, every iron hoop, camera angle, lighting,
position and size. Change only the inside of the open barrel: fill it with
believable discarded crumpled off-white newspaper sheets, folded kraft paper
and a used plain brown takeaway cup, naturally piled out of the opening.
Paper should have realistic folds, soft creases, small printed columns,
shadows and contact with the inside of the rim, not a stylized pile.
Let the tallest papers rise into the existing upper headroom without touching
the canvas edge; do not crop anything. Keep the FRONT lip visible and
unobstructed, with all rubbish behind it; do not drape rubbish down the front
or sides. All barrel body pixels below the opening must remain unchanged.
Match soft upper-left photographic light. Same square canvas.
IMPORTANT BACKGROUND for production extraction: replace the transparent/black
surrounding area with perfectly flat solid chroma-magenta #FF00FF, no
checkerboard, no gradient, no shadow on ground, no reflected magenta or color
spill on objects. Keep white paper true warm white. No scenery, no floor,
no UI, no labels, no logos, no extra objects beside barrel. This solid
background will be removed locally.
