EMBER GLOW THEME / IMPORTABLE THEMES
====================================

Build 1341 includes Ember Glow 1.2.2 as an installed theme, including the
corrected clock, revised dock, and two wallpapers. Fresh installations and
upgrades no longer require a separate Ember Glow import.

The separate EmberGlow-1.2.2.emilytheme file remains available for updating an
older EmilyDesk installation without running the complete installer:

1. Open EmilyDesk Dashboard.
2. Open Settings.
3. Select Import Theme.
4. Choose EmberGlow.emilytheme.
5. Choose Yes when asked to replace Ember Glow. The Ember Glow dock opens
   automatically; the theme is also available in Gallery, widget Theme menus,
   Designer, Dock Settings, and the tray Dock menu.

The two Ember Glow wallpapers are available from Dashboard > Wallpaper after
the updated theme package has been imported. Both 16:9 and 16:10 versions are
included.

Importing or replacing a theme does not delete personal layouts or settings.
Theme packages are installed to the current user's LocalAppData EmilyDesk
Themes folder. Future themes can use the same .emilytheme format and do not
require rebuilding or reinstalling EmilyDesk.

Keep the previous installer as the rollback copy. Build this working folder on
Windows with Build.cmd to produce the Build 1341 installer. The resulting
installer includes Ember Glow 1.2.2 automatically.
