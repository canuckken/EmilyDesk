EmilyDesk Weather Icon Packs
============================

Each icon pack is a folder containing transparent PNG files.

File names use the weather condition number:
  1.png (or 01.png)
  2.png (or 02.png)
  ...
  44.png

All PNGs in a pack should use the same canvas size and visual scale.
EmilyDesk preserves aspect ratio and falls back to its built-in icon whenever
the selected pack does not contain the requested condition number.

Use Designer > Weather Icons > Import Icon Pack Folder to install a pack.
