Industrial Weather Icon Pack

This is EmilyDesk's built-in Industrial condition pack.

The files are deliberately exported as 256 x 256 transparent PNGs with a
generous clear margin around the visible artwork.  Keep that safety margin
when replacing an icon: the same image is used both in the large current
condition area and in compact forecast slots.

File names use the existing weather-condition IDs, 1 through 44.
