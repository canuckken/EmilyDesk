EmilyDesk Recycle Bin Widget

Double-click the widget to open the Windows Recycle Bin. Files and folders can
be dragged onto the widget to move them to the Recycle Bin using the normal
Windows confirmation behaviour.

Right-click for Empty Recycle Bin, theme, scale, opacity, positioning,
layering, reload, reset and close controls.

All seven themes use the approved realistic empty/full artwork on a fully
transparent background. There is no caption box, title, count or size text.
The Windows desktop Recycle Bin icon feature is separate and remains available.
